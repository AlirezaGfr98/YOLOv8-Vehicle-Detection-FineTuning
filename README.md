# YOLOv8-Vehicle-Detection-FineTuning
Fine-tuning YOLOv8 (s, m, l) on a custom vehicle detection dataset (cars, trucks, buses, bicycles, motorbikes). Data augmentation applied to improve generalization. Models compared using Precision, Recall, and mAP metrics. Integrated with Weights &amp; Biases for experiment tracking. Includes training, validation, testing, and result visualization.
